# SDVX-CSV-Chart-Generator

**SDVX-CSV-Chart-Generator** is a WinForm application designed to analyze CSV data downloaded from the official SOUND VOLTEX website. It sorts the top 50 songs based on ratings in descending order with a precision of up to three decimal places.

---

## Key Features

- **Automatic CSV Parsing**: Effortlessly imports and processes CSV files.
- **Data Validation**: Ensures the integrity and accuracy of imported data.
- **Descending Rating Sort**: Automatically sorts songs based on their ratings.
- **Dynamic Table Creation**: Displays results in a table optimized for various screen resolutions.

---

## How to Use

1. Download the CSV file from the official SOUND VOLTEX website.
2. Open the application and import the CSV file.
3. View the top 50 songs sorted by rating in descending order, displayed with three decimal precision.
